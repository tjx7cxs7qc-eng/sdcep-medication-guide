# SDCEP Medication Guide

English and Chinese study tables based on **SDCEP Drug Prescribing for Dentistry**, organised into 19 treatment groups.

## View Online

- **[English medication tables](https://tjx7cxs7qc-eng.github.io/sdcep-medication-guide/index.html)**
- **[中文用药表格](https://tjx7cxs7qc-eng.github.io/sdcep-medication-guide/zh.html)**

No GitHub account is needed to view the website.

## What’s Included

- First-choice and alternative treatments
- Adult and child doses
- Treatment durations and administration instructions
- Contraindications and prescribing cautions
- Expandable NB notes and child age/weight bands
- Links to the original SDCEP guidance

Drug names remain in English in both language versions.

## Corrections and Suggestions

This resource is actively maintained. If you spot an error or would like to suggest an addition, please **[open a GitHub issue](https://github.com/tjx7cxs7qc-eng/sdcep-medication-guide/issues/new/choose)**.

Please include:

- The language version and relevant condition or section
- The error or suggested addition
- A link to the relevant SDCEP guidance

Contributions via pull requests are also welcome. All proposed changes will be reviewed against the relevant SDCEP guidance before inclusion. A GitHub account is required to submit an issue or pull request. Please do not include patient information.
