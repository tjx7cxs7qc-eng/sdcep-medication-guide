# sdcep-medication-guide
SDCEP medication reference website with English and Chinese pages and issue templates
## 🌐 Live Preview

View the medication tables online:

- **[English version](https://tjx7cxs7qc-eng.github.io/sdcep-medication-guide/)**
- **[中文版本](https://tjx7cxs7qc-eng.github.io/sdcep-medication-guide/zh.html)**

Includes first-choice and alternative treatments, adult and child doses,
treatment durations, administration instructions, contraindications,
NB notes, and links to the original SDCEP guidance.

## 💬 Feedback and Contributions

Found an error or have a suggestion?

**[Open an issue](https://github.com/tjx7cxs7qc-eng/sdcep-medication-guide/issues/new/choose)**

Please include the relevant condition and SDCEP guideline link.
Pull requests are also welcome.
